# Transformice Wiki Tracker

A small Chrome extension for tracking which Transformice badges, titles and chest items I already own.

![Transformice Wiki Tracker](./assets/transformice-wiki-tracker.gif)

## What it does

Click an item on the Transformice Wiki to mark it as owned. The state is saved locally, so it stays after refreshing the page.

The extension also highlights other occurrences of the same item on the page.

## Installation

[![Available in the Chrome Web Store](https://img.shields.io/badge/Chrome%20Web%20Store-Available-blue?logo=googlechrome)](YOUR_CHROME_WEB_STORE_LINK)

1. Open the extension's Chrome Web Store page.
2. Click **Add to Chrome**.
3. Confirm by clicking **Add extension**.

Once installed, open the supported Transformice Wiki page and the tracker will be ready to use.

## Usage

Open the supported Transformice Wiki page and click an item to mark it as owned.

Click it again to remove the owned state.

## Supported page

Currently, the extension works on the Transformice Wiki Chest page.
